## Update Rules

1. 每次完成一个“后端玩法模块”的基础联调后，先更新本文件，再继续下一个模块。
2. `基础版` 的最低标准：
   - 首次进入不报空指针/未支持协议
   - 至少一个主入口动作可完成闭环
   - 关键状态回刷正常
3. `完整版` 的最低标准：
   - 主玩法完整闭环
   - 常见奖励/刷新/二级页面可用
   - 退出重进后核心状态保持正确
4. 如果只是修 Unity 停止播放时的报错，不单独算玩法完成度提升。
5. 新发现玩法入口时，先加到清单，再判断状态。
6. 红点状态单独维护，不跟玩法完成度自动绑定。
7. 红点状态使用：
   - `未验证`
   - `待验证`
   - `正常`
   - `异常`
