\# DecodedConfig



\- `csv/`: readable table exports

\- `json/`: full-fidelity row exports

\- `meta/`: schema inferred from client config classes



\- Success tables: 121

\- Failed tables: 0





json 存的是每张表的完整数据内容，按“行数组”导出，尽量保真。
比如：

* cfg\_card\_model.json
每一项就是一行记录
数组、字典这些复杂字段会保留成 JSON 结构，不会被压平成字符串



meta 存的是每张表的结构说明，不是业务数据本身。
比如：

cfg\_card\_model.meta.json
里面主要有：

* class\_name：对应的客户端配置类名
* table\_name：表名
* row\_count：行数
* field\_count：字段数
* trailing\_bytes\_after\_parse：解析完后是否还有剩余字节，0 说明基本完整匹配
* fields：字段列表，每个字段会标明

  * name
  * type
  * reader
  * 

简单理解：

* csv：给人快速看
* json：给程序或详细检查用
* meta：告诉你“这张表是按什么结构解出来的”
